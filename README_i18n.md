# 02 모델 속 들여다보기 — 7개 언어판

global-i18n **언어팩 패치버전 VER1.0**으로 만든 한국어 원본 + 6개 외국어판입니다.

| 파일 | 언어 | 크기 |
|---|---|---|
| `index.html` | 시리즈 목차 (7개 언어 한 파일, `?lang=` 또는 브라우저 언어로 표시) | 151 KB |
| `02_models.html` | 한국어 (원본, v1.1) | 376 KB |
| `02_models.en.html` | English | 384 KB |
| `02_models.zh.html` | 简体中文 | 381 KB |
| `02_models.ja.html` | 日本語 | 396 KB |
| `02_models.ru.html` | Русский | 424 KB |
| `02_models.uz.html` | Oʻzbekcha (lotin) | 389 KB |
| `02_models.vi.html` | Tiếng Việt | 397 KB |

- **배치:** `layout: "suffix"` (`이름.언어.html`) — GitHub 웹 업로드용. 이 시리즈는 이 방식으로 고정합니다(시리즈 1).
- **언어 전환:** 상단 내비 오른쪽 선택 상자. `?lang=ja`처럼 주소에 붙이면 그 언어로 넘어가고, `#lv4` 같은 섹션 위치는 유지됩니다. 한국어판은 웹(http/https)에서 열 때만 브라우저 언어를 보고 자동으로 넘어갑니다(파일로 열거나 Claude 아티팩트 안에서는 넘어가지 않음).
- **목차:** `index.html`이 저장소 첫 화면입니다. 각 페이지 왼쪽 위 로고를 누르면 같은 언어의 목차로 돌아갑니다. 주차는 서로 독립된 페이지이므로 목차는 완성된 주차만 카드로 보여 줍니다(앞뒤 링크 없음). 새 주차는 `make_index.py`에 카드 하나를 더하면 됩니다.
- **검색 엔진:** 일곱 파일 모두 `<link rel="alternate" hreflang>`을 서로 가리킵니다.
- **지식 색인:** `kg-raw` 노드마다 `label.{언어}`·`definition.{언어}`를 더했습니다(영어판은 기존 `label.en` 유지, 이름 옆 영어 보조 이름 숨김). `kg-ld`(JSON-LD)는 손대지 않았습니다(시리즈 2).
- **글꼴:** zh Noto Sans SC, ja Noto Sans JP, en·ru·uz·vi IBM Plex Sans. zh·ja는 `word-break:normal`.

**이번에 고친 도구 오탐·사고 (다음 판에 반영할 것)**
1. 숫자 정규화가 `0.094`를 천 단위 구분으로 오인 → 소수점 규칙을 지키게 고침
2. `16분의 1만`의 `만`(= only)을 1만으로 환산 → `분의` 뒤 숫자는 건너뜀
3. `10만` = "100 тысяч" 허용 (만 → ×10 천 단위 표기)
4. CSS `content:"확인 퀴즈 · "`를 처음에 놓침 → style 영역 추출 추가. **새 단위는 id 맨 뒤에 붙여** 기존 묶음 id가 밀리지 않게 함 (중간에 끼웠다가 일본어 메모리 1건이 잘못 들어간 것을 찾아 지움)

## 다시 만들 때
```
python3 i18n/i18n.py roundtrip          # 원본과 같은지
python3 i18n/i18n.py pending ru         # 번역 메모리에 없는 단위만 묶음으로
(번역 AI: rules/common.md + rules/lang/ru.md + 묶음 1개 → *.out.json)
python3 i18n/run_all.py check ru        # 통과분 흡수, 실패 id 보고
python3 i18n/run_all.py merge           # dist/ 에 7개 파일
node i18n/browser_check.js dist/*.html  # 헤드리스 검사
```
한국어 원본을 고치면 바뀐 문장만 새 단위가 되어 그 부분만 번역됩니다(번역 메모리 `work/{언어}/tm.json`).
