# uz (Oʻzbekcha, lotin yozuvi)
- Latin script only. Write oʻ and gʻ with U+02BB (ʻ), and the tutuq belgisi with U+02BC (ʼ): maʼlumot, taʼlim. Never use ' or ` for these.
- Polite "siz" form. Clear, simple sentences; keep technical English terms when glossary has them in parentheses.
- Numbers digit for digit; decimal separator stays ".". 2,350억 → 235 mlrd, 220억 → 22 mlrd.
- Characters: Doktor, Yordamchi, Meva pashshasi tadqiqotchi, Money-Robo.
